# Previous frontend

Preserved Vite implementation from before the Next.js migration. These files are not served, imported, typechecked or linted by the active application. Active routes live in web/app, React components in web/components, typed clients in web/lib and styles in web/styles. Shared fonts and images remain in web/public.

The previous implementation is retained rather than deleting files during migration. Do not add new features here.
